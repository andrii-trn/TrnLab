Лабораторна робота №3

Варіант: Bookmarklet для розкладу (CIST NURE)

Створити bookmarklet для стилізації сторінки з розкладом з сайту https://cist.nure.ua для своєї групи. Виклик bookmarklet повинен приводити до зміни кольорового оформлення комірок, які містять рядок ВР Лб.

Посилання на розклад групи (приклад): відкрити розклад

Дія: підсвітити “ВР Лб” Повторний клік: прибрати (toggle) Працює з iframe (якщо доступні)
  1. Увімкни панель закладок (Bookmarks Bar) у браузері.
  2. Перетягни кнопку нижче на панель закладок.
  3. Відкрий сторінку розкладу.
  4. Натисни закладку — комірки з ВР Лб підсвітяться.
Підсвітити “ВР Лб”
Якщо браузер не дає перетягнути кнопку: створи закладку вручну і встав у поле URL код, який починається з javascript:.
